    🚫 Ban ?

    They won't be able to connect to this server with this identity any more. You can lift the ban from the same list.

    Also ban their address

    An address ban can block other people on the same network (shared Wi-Fi, a school, a mobile carrier), and a VPN or mobile data gets around it. A fresh install of Reson8 is a new identity, so this is the only thing that stops them coming back from the same place.

    Export identity

    Saves your identity — your user ID and the private key that proves it is you — in a file protected by a passphrase. Use it to move to another computer, or to restore it after a reinstall.

    Anyone with this file and its passphrase can act as you on every server. Keep it somewhere safe — and don't forget the passphrase: it can't be recovered.

    🔒 Your identity key is locked

    Reson8 couldn't unlock this install's identity key — the system keyring may have been reset or changed. The key was not replaced, and you can't connect until this is resolved.

    If you have an identity backup, import it. Otherwise you can create a new identity; a server admin will then have to reset your old one for you to keep your name and roles.
