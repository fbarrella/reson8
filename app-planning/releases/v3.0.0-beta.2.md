# 🎧 Reson8 v3.0.0-beta.2 Release Notes (Beta)

The second beta brings the new look: the Nocturne design, a server rail with saved servers, a redesigned server header and DM sidebar, a room view for voice with in-app screen sharing, and a corner card for updates. Earlier in this beta: [beta.1](v3.0.0-beta.1.md).

> [!WARNING]
> This is a beta. Install it only if you want to test the new interface.
> Beta builds update to newer betas automatically; stable builds never see
> them. To go back to stable, install 2.7.x from the Releases page.

> **Please check:** picture and sound on the in-app stream stage, the Viewer window and the Grid were not verifiable on the development machine. If a stream stays black or silent, please report it.

---

## ✨ New Features & Improvements

- 🎨 **The Nocturne Look** — A new colour system, the vendored Inter font and Phosphor icons, and shared menu, button, input and dialog styles across the app.
- 🗄️ **Saved Servers, Welcome Screen and Rail** — Servers you connect to are remembered with their icon; a welcome screen replaces the old connect box, and a rail on the left switches servers. Saved passwords are kept encrypted by the main process only.
- 🪟 **Server Pill and Status Bar** — The title bar shows the connected server with a switcher, and the status bar shows the client version, latency and encryption.
- 🏷️ **Server Header and Menu** — The sidebar header shows the server's icon, name and shared online count, with a menu that only offers what you may do.
- ℹ️ **About {server}** — A dialog with the address, encryption, measured latency, people online, admins and which features are on.
- 🖼️ **Server Icon** — Admins can upload, crop, replace and remove the server icon from Settings › Server.
- 📁 **Category Menu and Dialogs** — Rename a category with validation, or delete it and choose to keep or delete its channels, with live counts and the people in voice. Collapsed categories now stay collapsed.
- 💬 **DM Sidebar** — The rail's DM button lists everyone on the server, grouped Online/Offline, with last-message previews, unread counts and a rail total. The old Online Users window is gone.
- 📑 **Tab Overflow** — Tabs that don't fit collapse into an "{n} more" button with a list; the active tab always stays visible.
- 🔊 **Voice Room Tab** — Open the room from the voice dock or by clicking your channel: everyone as tiles in Mosaic, or Featured with a "…and n more" list, with speaking rings and the volume/mute menu on every tile.
- 📺 **Streams Inside the App** — Watching a screen share now plays in the room tab, with volume up to 200%, quality, fullscreen and a pop-out to the Viewer window (always-on-top, Return to Reson8). The sharer no longer hears a join/leave pair when someone pops out and back.
- 🧩 **Several Streams** — Focus shows one stream with the others as live cards; Grid shows every stream at once, each muted until you focus it.
- ⬆️ **Update Corner Card** — Updates appear as a small card instead of a window, with progress, an in-call note about restarting, and the full state in Settings › About.
- 📝 **What's New** — A redesigned release-notes dialog with issue chips, reopenable from Settings › About.
