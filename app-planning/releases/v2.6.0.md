# 🎧 Reson8 v2.6.0 Release Notes

This release adds a personal touch and a lot of everyday polish: avatars next to every message, a profile card for every user, tabs that stop piling up, social-media videos that play right in the chat, and a much louder mic option. It also closes an important security gap: your identity can no longer be borrowed by someone who knows your user id.

> **Please update the client and the server together.** An older (v2.5.0) client still works with a v2.6.0 server (it just doesn't show avatars), and a v2.6.0 client still works with an older server. The one exception is the new identity protection below: once you connect with v2.6.0, your identity can only be used from that install, so an older client using the same identity is refused.
>
> **Server admins:**
> - This version adds two small database migrations (avatars and identity keys). Docker deployments apply them automatically on start; otherwise run `npx prisma migrate deploy` in `apps/server` before starting the new server. Nothing existing is changed or deleted.
> - **Identity protection, recommended rollout:** update the server; connect with your updated client and copy your key fingerprint from **Settings → About → Identity** into `ADMIN_KEY_FINGERPRINT` in the server's `.env`, so only your key can ever be the admin; once everyone has updated, set `REQUIRE_SIGNED_IDENTITY=true` to refuse older clients entirely. Optionally, `AUTH_ALLOWED_HOSTS` restricts which server addresses a proof is accepted for. All three are optional and documented in `.env.example`.

## ✨ New Features & Improvements

- 🖼️ **Avatars** — Set your avatar in the new **Settings → Application → Profile** section: pick Libravatar or Gravatar, type the email you used there, and see a live preview (it even tells you whether a picture exists for that email). Your email never leaves your computer — only an anonymous hash of it is shared. Everyone else gets a fun generated avatar until they set one.
- 🙈 **Avatars Off Switch** — Prefer not to load images from Libravatar/Gravatar at all? Turn off "Load avatars from Libravatar/Gravatar" and everyone shows as colored initials instead, with no requests to those services.
- 💬 **Avatars in Chat** — Every message group in channels and DMs now shows the author's avatar on the left, with the following messages neatly indented under the name, and hovering a grouped message shows its time.
- 🪪 **User Profile Card** — Click anyone's avatar or nickname in a chat to see their profile: a bigger avatar, when they first joined, their roles, whether they're online, and shortcuts to **Message** or **Nudge** them. On your own card, "Edit profile" takes you to your profile settings.
- 🔖 **Preview Tabs & "Keep Tab Open"** — Clicking text channels no longer piles up tabs: the channel opens in a single preview tab (shown in italics) that the next channel replaces. Right-click a tab (or a channel) and choose **Keep Tab Open** to keep it — kept tabs get a bookmark icon and come back the next time you connect.
- 🔴 **Unread Dots on Tabs** — An open channel tab you're not looking at now shows a red dot and a bold name when new messages arrive (except for channels you've muted).
- 🎙️ **Microphone Volume up to 300%** — The mic volume slider now goes to 300%, and loud peaks above 100% are softly limited instead of crackling.
- 📜 **Longer Messages Stay Open** — Messages now only collapse behind "See more" when they're longer than about 15 lines (they still show 4 lines when collapsed), so warnings and longer posts are readable at a glance.
- ▶️ **Videos Play Right in the Chat** — Links to YouTube, X/Twitter, Instagram, Reddit, Twitch, Bluesky and Imgur now try an embed-friendly service first, so videos often play inline instead of only showing a thumbnail; clicking the preview still opens the original post. If that service is unavailable, you get the usual preview.
- ↕️ **Blank Lines in Messages** — A line containing just a space now shows as a real blank line, so you can separate paragraphs in longer messages.
- ⌨️ **Emoji Autocomplete While Editing** — Typing `:` and a letter now suggests emoji in the message edit box too, just like in the main chat box.

## 🐛 Bug Fixes

- 🔐 **Your Identity Is Now Protected (Security)** — Each install now has its own private key and proves it on every connection, so nobody can impersonate you (or the server admin) just by knowing your user id. Admins can see which users are protected in **Settings → User Management** (🔒) and use **Reset key** to help someone who reinstalled or moved to a new computer.
- 🖥️ **Safer Screen-Share Viewer (Security)** — The screen-share viewer window now signs in with a short-lived ticket from your own connection, so it can no longer be used to watch a channel's screen shares without being a member of it.
- 📌 **Pinned Message Jumps Work Again** — Clicking the pinned-message bar (or a reply snippet) now lands exactly on the message, even far back in the history, and you can keep scrolling down from there to newer messages.
- 📥 **Short Chats Load Their History** — In a chat whose first page of messages doesn't fill the window, older messages now load automatically instead of never appearing.
- 🕳️ **No More Gaps After Jumping Back** — A new message arriving while you're reading older history no longer gets placed in the wrong spot; you reach it by scrolling down, and sending a message takes you back to the latest ones.
- 📏 **Long Messages in Background Tabs** — Long messages that arrived in a tab you weren't viewing are now collapsed properly when you open it.
- 🗂️ **Deleted Channels Close Their Tab** — Deleting a text channel now closes its open tab.
- 🔤 **Cleaner Link Previews** — Special characters in link previews (like `&amp;`) now display correctly instead of as raw codes.
