# 🎧 Reson8 v2.8.0 Release Notes

This release adds an optional preview channel: if you'd like to try what's coming before a stable release, Reson8 can now offer you **beta (pre-release) builds** — and it stays completely off until you ask for it.

> **This is a client-only update.** There are no server or database changes, so nothing needs to be updated on the server side, and older clients keep working exactly as before.
>
> **Beta updates are opt-in and off by default.** Turn on **Settings → About → Register for beta tests** to receive beta builds; turn it off whenever you like to go back to stable releases only. If you installed a beta build on purpose, the switch starts on for you (and tells you why) so you keep getting betas — no re-checking required.

---

## ✨ New Features & Improvements

- 🧪 **Opt-In Beta Updates** — **Settings → About** has a new **Register for beta tests** switch. With it on, Reson8 also looks at pre-release (beta) builds published on GitHub and offers them through the same one-click update flow as stable releases; with it off (the default), you only ever get stable updates.
- 🔁 **Back to Stable Whenever You Want** — Flip the switch off and the next check follows stable releases only; a beta build you installed on purpose starts with the switch already on, so you're never stranded on an old beta.
- ⬆️ **Clear About a Beta** — The update prompt labels a pre-release as a **Beta Update** and warns it may be unstable, and the About tab's status tells you when you're being offered updates on the beta channel.
- 🛡️ **No Accidental Downgrades** — The beta channel never offers you an older build just because it's the newest beta; updates always move you forward.
