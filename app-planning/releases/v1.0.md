# 🎧 Reson8 v1.0 — Initial Release

**Self-hosted voice & text communication — your server, your rules.**

Reson8 is a high-performance desktop communication platform inspired by TeamSpeak 3, built from the ground up with modern technology. Own your data, deploy with a single command, and enjoy crystal-clear voice with your community.

---

## ✨ Highlights

- 🔊 **SFU-based voice** — Low-latency, scalable audio powered by mediasoup (WebRTC). No peer-to-peer bottlenecks.
- 🌳 **Hierarchical channel tree** — Categories, voice rooms, and text channels in a familiar TeamSpeak-style layout.
- 💬 **Rich text chat** — Per-channel messaging, direct messages, emoji picker, link previews, image sharing, and video embeds.
- 🛡️ **Role-based permissions** — Bitwise permission system with fine-grained admin controls, kick, and ban.
- 🐳 **One-command deployment** — `docker compose up` spins up the entire stack: server, PostgreSQL, and Redis.

---

## 🔊 Voice & Audio

- Crystal-clear SFU-based voice via mediasoup — scales to large groups without P2P bottlenecks
- **Push-to-Talk** with configurable global hotkey, or **Voice Activation** mode — toggle freely from settings
- **Active Speaker Indicator** — animated green halo highlights who's talking in the channel tree
- **Audio Device Selection** — choose microphone and speaker devices with an explicit save action
- Mute, Deafen, and Disconnect voice controls with tooltips
- Dual-announce IP support (`MEDIASOUP_ANNOUNCED_IP` + `MEDIASOUP_PRIVATE_ANNOUNCED_IP`) for LAN/WAN setups
- Full TURN relay support for Cloudflare Tunnel deployments (bundled coturn config)

## 🌳 Channels & Presence

- Hierarchical channel tree with categories, voice rooms, and text channels
- Real-time presence — see who's online and in which channel, instantly updated
- Channel CRUD — create, rename, and delete channels on the fly (permission-guarded)
- Occupant hydration on connect — existing voice users are visible immediately

## 💬 Text & Messaging

- **Tabbed text chat** — per-channel messaging with message history (cursor-based pagination)
- **Direct Messages** — private 1-on-1 conversations with:
  - Read receipts and unread indicators
  - Auto-open tabs for unread conversations on connect
  - **Offline access** — DM history persists even when the other user is offline
- **Image sharing** — upload images (paste or attach), inline thumbnails with lightbox viewer
  - Dual storage: local filesystem or Cloudinary CDN
- **Emoji Picker** — ~350 curated Unicode emojis with categorized tabs and search
- **Link Previews** — URLs auto-expand with title, description, image, and domain badge
  - YouTube/video embeds with inline playback
- Clickable URLs in messages — open in system default browser

## 🛡️ Administration & Security

- **Bitwise permission system** — ADMIN flag bypasses all checks, fine-grained role assignment
- **Role management UI** — assign Member / Server Admin roles per user
- **Server password protection** — optional `SERVER_PRIVATE_PASSWORD` env var
- **Kick from channel** — right-click context menu on occupants (admin only)
- **Ban from server** — persistent bans by instance ID with unban support in the Users modal
- Instance-based identity — persistent UUID per Electron installation

## 🖥️ Desktop Experience

- **System Tray** — minimize-to-tray and close-to-tray with configurable preferences
- **Remember Me** — saves server URL, nickname, and password across sessions
- **Right-click context menu** — native Cut, Copy, Paste, Select All
- **Multi-key shortcut combos** — configurable hotkeys for PTT, Mute, Deafen, and Disconnect
- **Settings modal** — tabbed interface (Roles, Voice & Shortcuts, Application)
- Links and video embeds open in system default browser

## 🏗️ Tech Stack

| Layer | Technology |
|:---|:---|
| Desktop Shell | Electron 33 |
| Language | TypeScript 5.7 |
| Voice Engine | mediasoup (SFU / WebRTC) |
| Signaling | Socket.io 4 + Fastify |
| Database | PostgreSQL 16 + Prisma |
| Presence | Redis 7 |
| Containerization | Docker Compose |
