# 🎧 Reson8 v1.4.0 Release Notes

This release is anchored by a comprehensive fix for random voice channel disconnects, and adds a new pinned-messages feature for text channels, a post-update "what's new" modal, and a couple of UI polish fixes.

---

## ✨ New Features & Improvements

- 📌 **Pinned Messages** — Admins can pin a single message per text channel. A bar above the chat shows a cropped preview of the pinned message; clicking it scrolls to and briefly highlights the original, even if it's further back in history than what's currently loaded. Pinning over an existing pin asks for confirmation first, and unpinning happens automatically if the pinned message is ever deleted.
- 🎉 **"What's New" Modal** — The first time you open Reson8 after an update, a one-time modal shows that version's release notes (pulled live from GitHub) with a link to the full release page.

---

## 🐛 Bug Fixes

- 🔊 **Random Voice Disconnects** — Voice channel participants could intermittently and unpredictably get dropped with no clear cause. Reson8 now automatically rejoins your voice channel after a brief network hiccup or a pure WebRTC connection drop, the server's ping timeout was retuned to avoid false-positive disconnects, and a crashed mediasoup worker no longer takes down every voice session on the server — only the channels actually affected.
- ⏱️ **Negative Voice Session Timer** — Fixed the voice channel timer briefly starting from a negative number (e.g. -1:00) before counting up, caused by uncorrected clock skew between the client and server.
- 😀 **Emoji Picker Custom Tab** — The custom-emoji tab could scroll out of view behind the built-in category tabs with no visible cue. It now has its own permanently-visible slot with a clearer icon.
