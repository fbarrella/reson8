# 🎧 Reson8 v2.0.0 Release Notes

Reson8's biggest release yet: **screen sharing** arrives, with optional native per-app audio capture on Windows and Linux, plus a broad wave of voice, chat, and admin fixes and improvements that followed it.

---

## ✨ New Features & Improvements

- 🖥️ **Screen Sharing** — Share a full screen or a specific application window with everyone in your voice channel, viewable in a dedicated pop-out Viewer window that anyone can open by clicking the sharer's LIVE badge — without leaving their current channel.
- 🔊 **Per-App Audio Capture (Windows & Linux)** — When sharing an application window, optionally include that app's own audio, scoped to just that app rather than your whole desktop, powered by a new native (Rust) capture module. Not available on macOS yet — screen sharing is disabled there for now.
- 🏷️ **Custom Stream Names** — Give your share a friendly display name instead of the raw window or app title.
- 🔴 **Sharer-Awareness Indicators** — A red banner and a full-width "Stop Sharing" button appear above your voice panel while you're actively sharing, and the window title shows a 🔴 so it's never ambiguous that you're live.
- 🛠️ **Server-Wide Screen Share Toggle** — Admins can enable or disable screen sharing for the whole server from Settings, mirroring the existing Nudge toggle.
- 🏢 **Server Name in Title Bar** — The window title now shows "Reson8 - [Server Name]" once connected, alongside the existing live-sharing indicator.
- 💬 **Admin-Configurable Message Length Limit** — A safe default cap on chat message length protects the server against oversized messages, with an admin override available in Settings → Server.
- ✂️ **Long Message Truncation** — Long chat messages now collapse behind a "See more" button. Expanded messages always re-collapse on their own — minimizing the app, switching away from the text channel, or relaunching all reset them, so nothing stays expanded longer than the session you expanded it in.
- 🔇 **Per-User Local Volume & "Mute Locally"** — Right-click anyone in a voice channel to adjust how loud they are just for you, or mute them locally, independent of everyone else's experience. A light-blue icon marks who you've locally muted.
- ⚠️ **Client/Server Version Mismatch Warning** — If your client and the server you're connected to are running different versions, you'll now see a warning with both version numbers — including a direct link to the latest release when the server is ahead of you.

---

## 🐛 Bug Fixes

- 🎥 **Black Video During Screen Share** — Fixed screen shares rendering solid black for every viewer, on every platform, caused by a VP9 encoder configuration that Chromium silently rejects for screen-content video.
- 🐧 **Linux/Wayland Double Picker & Redundant Modal** — On Wayland, Reson8 now defers directly to the OS's own screen picker instead of showing a second, redundant in-app selection dialog on top of it.
- 📦 **Packaging Build Failures** — Fixed `build:linux`, `build:win`, and the unified `release:all` script all failing outright due to how npm workspace symlinks interacted with electron-builder's packaging.
- ⏹️ **Viewers Not Notified When a Share Ends** — Fixed viewers only learning a screen share had ended when the sharer's entire voice session ended, instead of the moment they actually stopped sharing.
- 🔇 **Viewer Window Mute Button** — Fixed its icon and color not reflecting the actual mute state.
- 😀 **Emoji Picker Custom-Tab Icon & Scrollbar** — The custom-emoji tab's icon was invisible against the dark background; replaced with a visible icon, and the category tabs' scrollbar is now visible and easier to use.
- ✏️ **Stale Edit Button** — The "edit message" button no longer stays visible after its 2-minute edit window has expired.
- 👋 **Nudge Button Layout & Blink** — Fixed the Nudge button changing width during its cooldown countdown (misaligning the Online Users list) and briefly flashing back to its normal state when reopening that list.
- 🎚️ **Mic Gain Drift on Windows** — Disabled Chromium's automatic mic gain control, which has a documented history of quietly changing Windows' own input volume as a side effect.
- 👤 **"Unknown" Nicknames After Long Sessions** — Fixed usernames sometimes showing as "Unknown" in the Online Users list after a session ran for several hours, caused by a presence record silently expiring with nothing refreshing it.
- 🔇 **Deafen Not Applying to Late Joiners** — Fixed deafen only silencing participants who were already in the channel at the moment you toggled it — someone joining the channel afterward could still be heard.
- 🔊 **Per-User Volume & Mute Silently Not Working** — The local volume slider and "Mute Locally" button had no audible effect at all, caused by a Web Audio routing assumption that didn't hold for live WebRTC audio in this Electron build; rebuilt on a more direct audio-graph path.
