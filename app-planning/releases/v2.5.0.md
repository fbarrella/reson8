# 🎧 Reson8 v2.5.0 Release Notes

This release is about making conversations easier to follow and uploads sturdier: you can now reply to specific messages, attach several images at once with real previews, and see back-to-back messages grouped under one name, plus a round of chat polish (emoji autocomplete, muting channels, NSFW options) and an important security fix for how uploaded files are handled.

> **Please update the client and the server together.** An older (v2.4.0) client connected to a v2.5.0 server still works, but it will not show **new** images, custom emoji or channel icons stored on the server's own disk (images hosted on Cloudinary, and everything uploaded before the update, are unaffected), it shows only the first image of a multi-image message, and it shows replies as plain messages. Updating the client fixes all of that.
>
> **Server admins:** this version adds three small database migrations. Docker deployments apply them automatically on start; otherwise run `npx prisma migrate deploy` in `apps/server` before starting the new server. Nothing existing is changed or deleted.

## ✨ New Features & Improvements

- ↩️ **Replies** — Hover any message (in channels and DMs) and press the new Reply button; a bar above the input shows who you're answering, and your message appears with a faded one-line snippet of the original on top. Click the snippet to jump straight to it — even if it's far back in the history — and it updates if the original is edited or turns into "Original message was deleted" if it's removed.
- 🖼️ **Several Images Per Message** — Attach up to 10 images at once from the paperclip, by pasting, or by dragging them onto the chat. They appear as large preview cards above the input (and stay there after uploading), and sent images show as a tidy grid.
- 👁️ **Preview Before You Send** — Each attached image has an eye button that opens it full size with zoom, plus a trash button to remove it and a retry button if an upload failed.
- 🧱 **Grouped Messages** — Consecutive messages from the same person within 5 minutes now share one name and time (shown as HH:MM) instead of repeating them, with a full date and time on hover.
- 🧰 **Floating Message Toolbar** — React, Reply, Edit, Pin and Delete now live in a small toolbar that appears when you hover a message, so messages without reactions no longer reserve an empty row; reaction pills are also a little larger and easier to read.
- ⌨️ **Emoji Autocomplete** — Type `:` and a letter to get a floating list of matching emoji (standard and custom) above your cursor; use the arrow keys, Enter or Tab, or click to insert one. Typing a full name like `:red_heart:` turns it into the emoji.
- 🔕 **Mute Text Channels** — Right-click a text channel to mute it just for you: it fades in the channel list and stops showing unread indicators, and unmuting brings back anything you missed.
- 👀 **Highlight for the Open Channel** — The text channel you're currently viewing is highlighted in the channel list with a small eye icon, so it's easy to find on busy servers.
- 🔞 **"Don't Warn Me Again" for NSFW Channels** — Tick the box in the NSFW warning to stop being asked; you can turn the warning back on in Settings → Application.
- 🌫️ **Optional NSFW Image Blur** — A new setting in Settings → Application lets you choose whether images in NSFW channels are blurred (on by default).
- 🧹 **Automatic Cleanup of Unused Uploads** — Removing a picked image, or cancelling an emoji or icon upload, now deletes the file right away; files nobody ended up using are removed after 24 hours, and deleting a channel removes its images and icon. Self-hosters can also run `npm run uploads:prune` once to find and remove files left behind by older versions (it only lists them unless you add `--apply`).

## 🐛 Bug Fixes

- 🔒 **Safer File Handling (Security)** — The server now keeps its own record of every file it stores, and only the person who uploaded a file can attach it, once, as a message image, emoji or channel icon. This closes a hole where a modified client could reference someone else's file and cause it to be deleted, or post an outside link as an "attachment".
- 🗑️ **Deleting Now Really Deletes Files** — Deleting a message or DM, rejecting a custom emoji, or replacing a channel icon now removes the image files involved from the server, including every image of a multi-image message.
- 🪟 **Dropped Files Can't Take Over the Window** — Dropping a file anywhere on the app no longer makes the whole window navigate to that file.
