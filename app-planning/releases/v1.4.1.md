# 🎧 Reson8 v1.4.1 Release Notes

This is a small maintenance release that makes update-check failures diagnosable instead of a dead-end generic error.

---

## 🐛 Bug Fixes

- 🔄 **Silent "Could Not Check For Updates" Error** — The "Check for Updates" button in Settings → About now shows the actual reason an update check failed (e.g. a network or GitHub-release issue) instead of a generic "Try again later." message that gave no way to diagnose what went wrong.
- 🎉 **Missing "What's New" Modal on Update** — Clients updating from a pre-1.4.0 version (before the "What's New" modal existed) never saw it after the update, since the app couldn't tell that apart from a genuinely brand-new install. Fixed by reusing the client's persisted instance ID as a more reliable "has this app run before" signal.
