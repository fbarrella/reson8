# 🎧 Reson8 v2.4.0 Release Notes

This release is about making chat richer and connections sturdier: messages can now span multiple lines with Markdown formatting, emoji look the same on every operating system, the image viewer gains a full set of tools, and a long-standing bug that made users vanish from the online list after a quick reconnect is fixed.

> **Note:** the reaction hover card shows who reacted only when the **server is also updated to v2.4.0**. Everything else works against an older server.

---

## ✨ New Features & Improvements

- 📝 **Multi-Line Messages & Markdown** — Press Shift+Enter for a new line, and format messages with `**bold**`, `*italic*`, `__underline__`, `~~strikethrough~~`, quotes, lists, titles, `inline code` and code blocks. Older messages that happen to contain Markdown characters (like `*sigh*`) will now display formatted.
- 🖼️ **Redesigned Image Viewer** — A compact icon toolbar with zoom in/out (up to 200% of the image's real size, with mouse-wheel zoom and drag to pan), copy image, copy link, open in browser and download, plus a "Sent by" label showing who posted the image and when.
- 😀 **Reaction Hover Card** — Hover over any reaction for a second to see a larger emoji, its name, and who reacted with it.
- 🌐 **Same Emoji Everywhere** — Reson8 now ships Google's Noto Color Emoji, so emoji (including flags) look identical on Windows, Linux and macOS.
- 🪟 **Remembers Window Size and Position** — The app reopens at the size and position you left it (including maximized), falling back safely if that screen is no longer connected.
- 📌 **Easier-to-Spot Pinned Message Bar** — The pinned message bar now uses a dark yellow tone chosen for readability against the app's blue.
- 🚫 **Disabled Ban Button on Your Own Row** — In User Management your own row now shows a greyed-out Ban button instead of hiding it, keeping the list consistent.
- 🔍 **Clearer Connection Logs** — The Server Log tab now shows why you were disconnected and how long a reconnection took, and the server records more detail to help diagnose future connection problems.

---

## 🐛 Bug Fixes

- 🔌 **Users Showing Offline After a Quick Reconnect** — Fixed a server bug where, after a brief connection drop, the old connection timing out later would wipe your presence and voice session — leaving you missing from the online list and dropped from voice a second time.
- 🎙️ **Voice Halo Showing While Muted** — Your own speaking indicator now turns off the moment you mute, deafen, or release your push-to-talk key, so it no longer looks like you're being heard.
- 🧊 **App Freezing After Re-Opening on Windows** — Hardened how the window is restored when you launch Reson8 again while it's already running (and from the tray), to address cases where it appeared frozen until minimized and restored.
