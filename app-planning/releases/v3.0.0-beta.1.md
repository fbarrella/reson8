# 🎧 Reson8 v3.0.0-beta.1 Release Notes (Beta)

The first beta of Reson8 3.0 is about how the app *behaves*: unread counts, tabs that follow clear rules, menus that only show what you may do, a server that tells members more about itself, and a handful of security hardenings. The new look arrives in the next betas — this one still looks like 2.7.0.

> [!WARNING]
> This is a beta. Install it only if you want to test the new interface.
> Beta builds update to newer betas automatically; stable builds never see
> them. To go back to stable, install 2.7.x from the Releases page.

> **Server admins — please read:**
> - This version adds one database migration (the server icon columns). Docker deployments apply it automatically on start; otherwise run `npx prisma migrate deploy` in `apps/server` before starting the new server. Nothing existing is changed or deleted.
> - A 3.0 beta client keeps working against a v2.7.0 server (features that need the new server simply fall back), and a v2.7.0 client keeps working against this server.
> - **Uploads are now checked by their real bytes** (see Bug Fixes): a file that isn't really a PNG, JPEG, GIF or WebP is refused, whatever its name or declared type says.

---

## ✨ New Features & Improvements

- 🔴 **Unread Counts** — Channels and DM tabs show how many messages you haven't seen (up to "99+") instead of a bare dot. Your own messages never count, and a channel only counts as read when you are really looking at it in a focused window.
- 🔕 **Muted Channels Are Quiet** — A muted channel fades, shows a bell-slash, and its tab is faded and badge-less; unmuting brings the count back.
- 🗂️ **DM Tabs Behave Like Channel Tabs** — A DM opened by clicking a person is a preview tab that the next conversation replaces; double-click or right-click → **Keep open** to keep it. Incoming DMs now open as kept tabs in the background instead of taking over your view, and kept DM tabs come back after a reconnect.
- 📑 **More Tab Menu Actions** — Right-click a tab for **Close other tabs** and **Close tabs to the right** (also on DM tabs); the Server Log is never closed.
- 🧭 **Menus Only Show What You Can Do** — The channel menu hides the "Manage channel" group (Rename, Set icon, Move, NSFW, Delete) unless you may manage channels, and a member gets no empty menu on a voice channel.
- 🔊 **Better Voice Participant Menu** — Volume with live readout and 0/100/200% marks, "Mute locally" (only for you), Kick only for people who really have the permission (including roles that have Kick but not role management) with a confirmation toast, and a **Voice settings…** shortcut on yourself. Local volume and mute now show in the tree as "{n}%" and a muted icon.
- ⚠️ **Deleting a Voice Channel Says Who Is Affected** — The dialog tells you how many people will be disconnected, and keeps the number current while it's open.
- 👥 **Voice Room Count and Timer** — The count pill has a person icon and a "{n} people connected" tooltip, and the session timer is correct from the moment you connect, even after a kick or an access change.
- 🖥️ **Five Screen Shares per Room** — A room carries at most five shares at once; a sixth is refused with a clear message (and its capture is stopped), and the Share button reads "Share screen · 5/5" when the room is full.
- 📁 **Deleting a Category Can Keep or Delete What's Inside** — The server now supports deleting a category together with its channels or moving them to the top level (the dialog for it comes with the new interface), and a deleted voice room is torn down on the server so nobody is left "connected" to it.
- 🖼️ **Server Icon (Groundwork)** — The server can store, replace and remove an icon (admin only, checked by its real bytes, cached forever); the settings, the live broadcast and the server summary carry it. The picker comes with the new interface.
- 📋 **Server Summary and DM Directory (Groundwork)** — Any member can ask the server for its name, member and online counts, admins and enabled features; and for everyone they could message, with the latest message and unread count per conversation.
- 🧾 **Your Own Permissions** — The client now knows what you may do and updates live when your roles change, so buttons and menus can follow it.
- 🔄 **Calmer Updates** — One update state drives the update dialog, the About page and a dot on the settings gear. An update that finished downloading **no longer restarts the app by itself**: choose **Restart now** or **On next launch**, and read the release notes of a pending update before installing.
- 🆕 **What's New Never Interrupts a Session** — The post-update notes appear only before you connect.
- 🏷️ **Beta Release Pipeline** — Betas are published on their own update channel and compared correctly (`3.0.0-beta.1` is newer than `2.7.0`, and older than `3.0.0`); stable users are never offered a beta.

## 🐛 Bug Fixes

- 🛡️ **Uploads Are Validated by Their Real Bytes (Security)** — Every upload route used to trust the declared type and the file's own name, so a crafted request could store an HTML file as an "image" on the server's public path. Files must now really be a PNG, JPEG, GIF or WebP, and are stored under the extension of what they actually are.
- 🛡️ **Screen-Share Switch Is Enforced Everywhere (Security)** — With sharing switched off, a modified client could still produce screen media or receive a share directly. Screen media is now only produced while sharing is on, and only received through the viewer of the sharer you are watching.
- 🛡️ **A Failed Sign-In No Longer Leaves a Half-Signed-In Connection (Security)** — A join that failed on a database error could leave the connection able to use signed-in features.
- 🌳 **Voice Rooms No Longer Look Empty After a Channel Change** — Creating, renaming, moving or deleting a channel used to blank every voice room's participants for everyone until the next presence update.
- ⏱️ **Voice Timer Survives Kicks and Access Changes** — A kick or losing access made other people's clients drop the room timer even though the room was still occupied.
- 🔎 **Mismatched Version Warnings** — The client/server version warning now understands beta versions instead of picking the wrong side.
- 🧪 **Developer Tooling** — Script files keep Unix line endings on every checkout so the whole server test suite loads on Windows.
