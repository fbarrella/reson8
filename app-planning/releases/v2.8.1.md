# 🎧 Reson8 v2.8.1 Release Notes

A small patch that makes the beta-update channel added in v2.8.0 actually work: with **Settings → About → Register for beta tests** turned on, Reson8 now reliably finds pre-release builds instead of sometimes reporting that you're already up to date.

> **This is a client-only patch.** There are no server or database changes, and older clients keep working as before.
>
> **If you turned on beta tests in v2.8.0, update to v2.8.1 for it to take effect.** v2.8.0 asked GitHub for a beta the wrong way: it looked at the most recently *created* release rather than the newest *version*, so a stable release published after a beta would hide that beta. v2.8.1 chooses the release itself, so betas are found regardless of the order GitHub lists them in. Stable releases are unaffected either way.

---

## 🐛 Bug Fixes

- 🧪 **Beta Updates Reach Testers Again** — With "Register for beta tests" on, Reson8 could still answer "You're up to date" even though a beta had been published. It was picking a release by GitHub's listing order (most recently created first) instead of by version, so a stable release published after a beta shadowed it. Reson8 now reads the release list and picks the newest **version** itself, so a beta is offered whenever one is actually newer than what you have — and a pre-release's update always comes from its own beta metadata.
- 🛡️ **Still No Downgrades** — The beta channel never offers you an older build just because it happens to be the newest beta; updates always move you forward.
- 🔒 **Stable Stays Stable** — With the switch off (the default), nothing changes: you are only ever offered stable releases, exactly as before.
