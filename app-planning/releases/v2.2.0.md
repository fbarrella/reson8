# 🎧 Reson8 v2.2.0 Release Notes

A voice-quality-focused release — real AI noise cancelling, a working mic volume slider, and a smoother noise gate — alongside a broad wave of chat, emoji, and admin improvements, plus two important fixes to how reliably the app connects and how accurately it reports who's actually online.

---

## ✨ New Features & Improvements

- 🤖 **AI Noise Cancelling** — A new toggle in Voice & Shortcuts runs a real AI denoising model (DeepFilterNet3, via WebAssembly) on your microphone in real time, suppressing keyboard clicks, fan noise, and other background sound without needing to fully gate your mic. Fully self-hosted — no data ever leaves your own server.
- 🎚️ **Microphone Volume Slider** — Adjust your own mic's input level from 0–200%, independent of your OS's mic settings — useful for a quiet mic that needs a boost, or to turn your own input down.
- 📊 **Always-Visible Mic Level Meter** — The microphone level meter in Voice & Shortcuts is no longer tied to the noise gate — it's now always on, so you can watch every change from noise cancelling, the gate, or the volume slider reflected live.
- 🙈 **Blurred NSFW Image Thumbnails** — Images posted in NSFW-flagged channels now render blurred in the chat feed by default, with a "Click to reveal" overlay; only the full-screen viewer ever shows them clearly.
- 📅 **Date Sectioning in Text Chat** — Messages are now grouped under `--- Month Day ---` dividers as you scroll through history, so it's finally obvious which day a message was sent on (older messages also show the year).
- 🎬 **Animated Custom Emoji** — Upload an animated GIF as a custom emoji via a dedicated "GIF+" button that skips the crop tool entirely, so the animation is preserved. Goes through the same admin-approval queue as static emoji.
- 🔍 **Bigger Solo-Emoji Messages** — A message containing nothing but a single emoji (Unicode or custom) now renders at roughly 4x size — a message with any other text is unaffected.
- 🔊 **Screen-Share Sound Alerts** — Four new sound cues: hear when someone starts or stops sharing their screen, and (if you're the one sharing) hear when a viewer opens or closes the Viewer window on your stream.
- 🛡️ **"User Management" Tab (formerly Roles)** — Ban and Unban moved out of the Online Users list into a renamed Settings tab that already lists every user on the server, online or not — offline troublemakers can finally be banned.
- 🔒 **Single-Instance Lock** — Opening Reson8 while it's already running now just focuses the existing window instead of launching a redundant second instance.
- ❌ **Close Button on Full-Screen Image Viewer** — A dedicated close button now sits alongside the download button, so closing an expanded image no longer requires guessing that the dark background is clickable.
- 📞 **New "Leave Voice" Icon** — Replaced the plain X with a hang-up-phone icon that reads more clearly as "drop the call."
- 📝 **Markdown-Rendered "What's New" Modal** — The post-update modal now renders the GitHub release notes as formatted text (headings, bold, lists, links) instead of showing the raw markdown syntax verbatim.

## 🐛 Bug Fixes

- 👻 **Stale "Online" Status After Quitting** — Fixed the app never telling the server it was intentionally quitting, so it always waited out the same multi-second grace period reserved for flaky network drops before marking you offline — meaning anyone who checked shortly after you closed the app would still see you as online. The app now signals an intentional quit explicitly, and the server updates everyone else's view within a couple of seconds instead.
- 💥 **App Failing to Connect After a Fresh Install/Update** — Caught and fixed a packaging issue in the new noise-cancelling feature's dependency that could crash the entire app at startup (no Connect button response, no instance ID shown) before it ever shipped.
- 🎙️ **Choppy Noise Gate** — The microphone noise gate now fades audio in and out smoothly (with a brief hold before fading) instead of cutting it off abruptly mid-sentence whenever your voice level dipped near the threshold.
- ⚡ **Sluggish Active-Speaker Indicator** — The green "speaking" halo around a participant now lights up noticeably faster.
- 📜 **"See More" Button Position** — Fixed the long-message "See more"/"See less" button appearing to belong to the wrong message (landing below the emoji reactions instead of above them), and restyled it as a pill-shaped button; also fixed it briefly showing on solo-emoji messages that had nothing to truncate.
- 🖱️ **Voice Participant Name Cursor** — Hovering a participant's name in a voice channel now shows a pointer cursor, making it clearer that right-click actions are available.
- 🔢 **Low-Contrast Participant Count** — The voice channel occupant-count badge is now easier to read against the channel tree background.
- 😀 **Tiny Custom-Emoji Tab Icon** — Enlarged the custom-emoji picker tab's icon for better visibility.
- 📐 **Settings Tab Bar Overflow** — The Settings modal's tab bar now scrolls horizontally instead of squishing or clipping tab labels once more tabs were added.
