# 🎧 Reson8 v2.1.0 Release Notes

This release focuses on connection resilience: Reson8 now rides out weak or flaky network conditions far more gracefully, instead of visibly and audibly disrupting everyone in the channel every time one person's signal blips.

---

## ✨ New Features & Improvements

- 🔁 **More Persistent Reconnection** — The client now keeps retrying a dropped connection indefinitely (with a capped backoff) instead of giving up after a handful of attempts and requiring you to manually reconnect.
- 🔏 **More Reliable Windows Code-Signing** — Code-signing credentials for official Windows builds now load automatically during the release build, removing a manual step that could previously be skipped by accident and ship an unsigned installer.

---

## 🐛 Bug Fixes

- 📡 **Connection Drops on Weak Networks** — A brief network hiccup (a few seconds of a weak WiFi or mobile signal) no longer disrupts everyone in your voice channel. Reson8 now tries to recover a degraded voice connection in place first; and if the underlying connection itself drops and quickly reconnects, the server gives it a short grace period before treating it as an actual departure — instead of everyone hearing a leave-then-join sound pair and watching you briefly vanish from the occupant list.
