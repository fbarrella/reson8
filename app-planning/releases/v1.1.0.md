# 🎧 Reson8 v1.1.0 Release Notes

This release brings several highly requested UX enhancements, new interactive chat features, audio upgrades, and important stability fixes to make the Reson8 experience smoother.

---

## ✨ New Features & Improvements

- 🔔 **Sound Alerts System** — Added 16 audible notifications for key application events. You'll now hear cues for joining/leaving voice channels, direct messages (smartly muted if the window is focused), muting/deafening, and moderation actions.
- 🎚️ **Mic Sensitivity Slider (Noise Gate)** — Say goodbye to background keyboard typing or fan noise. Configure a custom decibel threshold in settings to automatically gate your mic when you aren't speaking. Includes a live audio level meter to help calibrate your perfect threshold.
- ⏱️ **Voice Session Timers** — Voice channels now display a live elapsed timer, giving you instant context on how long a conversation has been active before you jump in.
- 😀 **Emoji Reactions** — You can now react to messages in text channels and direct messages using the built-in emoji picker! Reactions are persistent, tally up automatically, and you can add to existing reactions simply by clicking them in the chat.
- 📶 **Real-time Latency Display** — Keep an eye on your connection quality with a new live ping latency display (in ms) located in the status bar, dynamically color-coded based on connection health.
- ⚙️ **Always-Accessible Settings** — The settings menu is now available even when you are disconnected from a server, allowing you to tweak your audio devices and application preferences globally at any time.

---

## 🐛 Bug Fixes

- **Production Tray Icon** — Fixed a packaging issue where the system tray icon was invisible in production builds (AppImage, Windows setup, etc.).
- **"Unknown" Nicknames on Reconnect** — Resolved a timing issue where users would randomly appear as "Unknown" in the channel tree following a network drop and automatic reconnection.
- **Duplicate Joins on Reconnect** — Fixed a bug where the client might send multiple join events simultaneously during flaky network conditions or auto-reconnects, minimizing potential ghosting bugs.
