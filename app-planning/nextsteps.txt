- Voice & Text Channels:
    - [IMPROVEMENT][VOICE CHANNELS] "Per-user volume levels" - While on a voice channel with other users, you should be able to set a custom volume by user. Everyone starts with 100% volume by default, but if you see that someone is being too loud, you can change its specific volume to be lower if you want. This setting is not global, it should be by client, so any changes I make to someone volume will not be reflected to the other voice channel participants clients

    - [IMPROVEMENT][VOICE CHANNELS] "Mute a single user" - On the same page as the volume control, you should be able to mute users to yourself. Once again, this is not a global action, it should happen only on the client where the action was taken. So, if I mute someone, then this person is only muted to me, not to the other voice channel participants. This option should be put into an right-click context menu that appears when right-clicking an voice channel participant name.

    - [IMPROVEMENT][VOICE CHANNELS] "Icons to signal when someone has muted itself or when it deafens itself" - Currently, when someone decides to mute its own mic, or to go deaf, the other call participants can't see that. So for everyone else it seems like the user is just ignoring them. Let's set an small (but visible) svg icon that shows by the side of the user name into the voice channel to make it visible to everyone whenever any of the two happen. I think the color for the icons should be red.

    - [IMPROVEMENT][VOICE CHANNELS] "Improve the session timer visibility" - Currently the session timer is a gray text on a dark background and that makes it hard to see, so let's follow good practices for UI and make the visibility better for the timer.

    - [IMPROVEMENT][VOICE AND TEXT CHANNELS][ADMIN ONLY] "Enable voice and text channel post-creation editing" - Right now, after a channel is created, you can't change its name. So let's enable this type of editing to make it easier to manage a server.

    - [IMPROVEMENT][VOICE AND TEXT CHANNELS][ADMIN ONLY] "Implement a way to fiddle with the channels ordering" - Right now, if you create a channel named "1" after one named "2" was created, the order of creation goes 2, 1 and you can't change that in any other way that is not deleting both of them and creating everything again. To make this easier, let's enable for the admin to drag and reorder the channels. This might be a big change and involve both the server and the client so let's make this carefully.

    - [IMPROVEMENT][TEXT CHANNELS][ADMIN ONLY] "Mark a text channel as NSFW" - We should have a option to create a channel and set it as "Not Safe For Work" if the channel nature is to send these types of messages. This option should be editable just as the channel name, so the channel can be unmarked as NSFW if it is the case. Also, on channels MARKED as NSFW, every user should receive a modal prompt alerting that the user is just about to enter a NSFW channel and check if he really wants to open it or if it wants to cancel the action. It is only after the user answers the prompt that, if the answer was positive, the text channel shall be opened.

    - [IMPROVEMENT][TEXT CHANNELS] "Upload custom emojis to server" - Any user should be able to upload custom emojis to be used everywhere an emoji is usable into the server. The emoji picker should have a "+" tab with the custom emojis and, inside the tab, an button to open a modal to register a new emoji. To upload a new emoji, the user should send a image type file (with maximum of 500kb in size) and set a unique name for it. After the user has sent the image, a crop tool should appear with the sent image to enable for the user to crop it on the correct dimension and format for the final emoji. When it is all correctly done, the emoji should appear as usable on the "+" tab in the picker.

    - [IMPROVEMENT][TEXT CHANNELS] "Add missing basic default reaction emojis on the picker" - Nowaday, emojis are a basic feature from a lot of applications. Between most applications, there is what is considered to be a agreement on which are the basis for the default emojis list. Currently our app misses some of these considered "default" emojis. Let's make sure that we don't miss any and add them to the picker.

    - [IMPROVEMENT][TEXT CHANNELS] "Users should be able to delete its own messages" - This is a simple one, users should be able to remove its sent messagens from a text channel and a direct message chat whenever they want to. For image messages, the deleting action should remove the picture from the server storage in use.

    - [IMPROVEMENT][TEXT CHANNELS] "For a limited amount of time, users should be able to edit its messages" - For a time interval of about 2 minutes, a user should be able to edit its own messages to correct or add missing information for it. Only text messages in this case, not sent images. After the 2 minutes interval, messages are unchangeable. Also, if a message is successfully edited, an "Edited" mark should appear by the side of the timestamp info for everyone to see.

    - [IMPROVEMENT][TEXT CHANNELS] "Instant visual feedback whenever user uploads an image" - Currently, when a user uploads an image to send via text chat or dm chat, the image gets sent and then nothing shows on the client until the image finishes being uploaded. This makes so the user can't be sure if the image was properly sent or not. To make the user experience better in this case, we should implement an instant visual feedback to serve as a placeholder that properly indicates that the image is actually sent but it's still uploading. Then, when the upload finished, the attachment can finally appear normally just as it does right now.

    - [IMPROVEMENT][TEXT CHANNELS] "New Unread Messages visual cue on text channels" - Currently there's no way to see whenever there are new unseen messages on the server text channels. A user should be able to know when there are new messages on any text channels that weren't active on its client. For this, maybe a red dot by the side of the text channel name + the text channel name font being bolder will serve as an visual cue. If there is no controll over if a user has seen the messages on a text channel or not, we should also implement this, so this way we properly enable the visual cue implementation. 

- Reson8 Client
    - [NEW FEATURE] "Nudge" - Users should be able to nudge other users (in order to get its attention). This feature should be toggled on or of by an admin on the server settings, and it should also have a cooldown per user. So, if you nudge someone, then you would be unable to do it again in at least 30 seconds. This is a default setting and it should be unchangeable. The nudge option should appear on the user list and it should only be applicable to online users.

    - [IMPROVEMENT] "Mute/Unmute and Deaf/Undeafen shortcuts aren't triggering its respective sound alerts" - The existing sound alerts for the mute/unmute and for the deaf/undeafen buttons are being triggered only by clicking on them. When the actions are activated via keyboard shortcuts, the same sound alerts should be triggered, but they currently aren't. Let's fix this.
